# Инструкция по разметке сообщений домовых чатов

Единая для эталона жюри и для участников, которые размечают данные сами.

Каждое сообщение получает три метки и, для тестовых данных, необязательные теги сложности.

## 1. `is_service` — служебное сообщение (0/1)

`1` — сообщение, которое **не является репликой жителя в живом общении**:

- автоматические рассылки ботов («Счета за июнь уже доступны в приложении «Госуслуги Дом»…», «Пора передать показания»);
- официальные объявления УК, РСО, администрации, регоператора: графики отключений, промывки, вакансии УК, правила проживания, протоколы собраний, оформленные как объявление;
- реклама и спам: услуги, магазины, доставка, каналы, «открытки», розыгрыши, приглашения на мероприятия от организаций;
- массовые пересылки новостей и агитации, не связанные с обсуждением.

`0` — всё, что пишут жители, в том числе информационные сообщения, вопросы, фото и медиазаглушки (`[image]`, `[video]` и т. п.). Ответ сотрудника УК конкретному жителю в ходе диалога («заявку передали мастеру») — тоже `0`: это часть общения.

Подсказки: текст, дословно повторяющийся в разных домах; отправитель, пишущий в десятки чатов; оформление с заголовком, эмодзи-буллетами и подписью организации.

**Для `is_service = 1` ставится `sentiment = neutral`, `aggression = 0`.** Служебные сообщения не участвуют в оценке тональности и в агрегатах настроения жителей.

## 2. `sentiment` — тональность автора: `negative` / `neutral` / `positive`

Оценивается **эмоциональное отношение автора**, а не тема сообщения.

**negative** — недовольство, жалоба с оценкой, раздражение, гнев, возмущение, тревога, страх, грусть, разочарование, негативный сарказм, оскорбления, угрозы.

- «Опять нет горячей воды, сколько можно!!!»
- «УК как всегда ничего не делает»
- «Ну спасибо, дорогая УК, третий день без лифта» (сарказм)
- «Страшно детей выпускать во двор»

**neutral** — информация, вопрос, просьба, объявление жителя, констатация факта без выраженной эмоции, формулы вежливости, медиазаглушки.

- «Нет горячей воды в 3 парадной?» — вопрос о проблеме без оценки, это `neutral`.
- «Доброе утро, кто знает телефон диспетчерской?»
- «Отдам детское кресло»
- `[image]`

**positive** — благодарность, радость, одобрение, поддержка, поздравления, доброжелательный юмор.

- «Спасибо, воду дали!»
- «Молодцы ребята, двор стал чистым»
- «С праздником, соседи! 🌸»

Спорные случаи:

- Смешанная тональность («Спасибо, что починили, но через неделю опять сломалось») — по итоговому смыслу, обычно `negative`. Тег `mixed`.
- Эмодзи-реакции: 😂👍❤️ — `positive`; 😡🤬 — `negative`; 🤔 — `neutral`.
- Мат как выражение эмоции без адресата («бл…, опять отключили») — `negative`, но `aggression = 0`.

## 3. `aggression` — агрессия, хамство (0/1)

`1` — оскорбление, унижение, переход на личности, угроза, грубость **в адрес людей**: соседей, участников чата, сотрудников УК, организаций, если это ругань, а не критика.

- «Вы тупая, читать не умеете?»
- «Х.. невшие, уберите за своей собакой»
- «Контингент тут скудный, порядочных единицы»

`0` — резкая, но предметная критика без оскорблений («УК не выполняет обязанности, напишем в ГЖИ»), мат без адресата.

`aggression = 1` всегда сочетается с `sentiment = negative`.

## 4. Теги сложности `tags` (только тест, через `|`)

| тег | когда ставится |
| --- | --- |
| `sarcasm` | ирония или сарказм: буквальный смысл противоположен реальному |
| `obscene` | мат, в том числе замаскированный (`х..`, `б***`, `пи@#ец`) |
| `typos` | сильные опечатки, нет пунктуации, «потоком» |
| `jargon` | жаргон и аббревиатуры ЖКХ: ХВС, ГВС, МОП, ОДН, ИПУ, ОДПУ, РСО, ЕИРЦ, капремонт, «управляйка», «парадная» |
| `emoji` | смысл передан в основном эмодзи |
| `mixed` | смешанная тональность |
| `context` | тональность понятна только из соседних сообщений |

Теги не оцениваются напрямую: по ним жюри считает качество на сложных подвыборках (критерий 3).

## 5. Маркеры обезличивания

`[имя] [телефон] [email] [ссылка] [ник] [адрес] [квартира] [грз] [номер]` заменяют персональные данные. На тональность они не влияют: «[имя], спасибо!» — `positive`.
